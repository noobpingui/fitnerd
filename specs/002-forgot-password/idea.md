# Idea original · 002-forgot-password

Fecha: 2026-10-05

Funcionalidad para que los usuarios que tienen password, osea que se registraron con correo y password tengan la opcion en la pantalla de login para poder hacer un password reset. La idea simple, un 'forgot password link' que al darle click permita que el usuario ingrese su correo electronico y reciba un link para reiniciar su contrasena. Este link debe llegar inmediatamente al correo en cuestion, solamente se puede enviar 1 vez cada dos minutos para evitar spam y el link caduca a los 5 minutos o si se envio otro posteriormente, el mas reciente siempre invalida al ultimo.
